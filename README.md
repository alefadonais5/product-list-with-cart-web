# Product List with Cart Web

Um projeto de lista de produtos com carrinho de compras, desenvolvido com TypeScript, HTML, SCSS e JSON. Os usuários podem visualizar produtos, adicioná-los ao carrinho e gerenciar a quantidade de itens de forma interativa.

## Tecnologias Utilizadas
- **TypeScript**
- **HTML**
- **SCSS**
- **JSON**
- **Vite**

## Estrutura do Projeto

- **data.json**: Armazena os dados dos produtos.
- **index.html**: Estrutura principal da página.
- **index.scss**: Estilização com SCSS.
- **app.ts**: Gerencia os produtos e o carrinho.
- **product.ts**: Classe `Product` para representar os produtos.
- **cart.ts**: Classe `Cart` para gerenciar o carrinho.

## Como Executar

1. Clone o repositório:
   ```sh
   git clone https://github.com/alefadonais5/product-list-with-cart-web.git
   ```
2. Acesse o diretório:
   ```sh
   cd product-list-with-cart-web
   ```
3. Instale as dependências:
   ```sh
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```sh
   npm run dev
   ```
5. Acesse no navegador o endereço indicado no terminal.

## Funcionalidades
- Lista de produtos carregados via JSON.
- Adição e remoção de produtos do carrinho.
- Atualização dinâmica do preço total.
